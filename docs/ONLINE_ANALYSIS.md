# 实时在线分析

在同一 EEG 工作台左侧点击“实时在线分析”，或打开 `/online`。新增分支使用现有城市巡航 CDT 原始文件、冻结 VRMSModel 权重和 mamba-minimal CPU 后端；现有离线分析及旧 `/monitor` 保持原合同。

## 使用

按原启动命令运行服务，然后选择原始记录并启动。默认 1 倍速、每 5 秒更新一次。页面下方可展开每条路径的本地结果、三个 Agent 解释与汇总，并下载 JSON 或 Markdown。暂停保留滤波、事件和路径状态，只停止新样本到达；已经到达的计算允许完成。继续后补偿暂停时间，不把暂停当成信号断流。停止后需创建新会话，重新进行 5 秒预热。

本机代码更新后的服务重启由 `scripts/restart_local_service.ps1` 处理：先核验在线、离线和云端任务空闲，再核验端口进程属于本项目，隐藏启动新版服务并检查健康、目录和在线页面。运行记录写入独立 `outputs/service_restarts/`。有分析正在运行时保留原进程，待分析结束后再由维护端执行；不会要求用户反复手动停启服务。

本地推理不需要云端。勾选“路径结束后调用云端”时，仅在实际收到路径结束事件后请求 VRMS 判断、疲劳与情绪/工作负荷解释及 Supervisor 汇总。未配置接口仍可本地回放。云端队列独立，不阻塞后续信号；停用、超时或格式/来源核验失败时，云端类别不会由本地类别代替。

在线整路径请求独立使用 `online_cloud_timeout_seconds`，默认每次 120 秒，可配置为 1–600 秒；离线接口的 `api_timeout_seconds: 10` 保持原值。每条完整路径依次执行四个云端阶段，不自动重试。加速回放可能快于云端队列的处理速度；队列满时明确记录该路径的失败原因。超时、连接、认证等请求失败与真实的格式/来源核验失败分别显示，已成功的领域解释保留。旧报告按保存的错误类型显示具体原因，不改写历史文件或补造云端类别。

波形仅调整网页显示尺度，每个通道标出当前 ±μV，原始值、滤波、质量门控和模型输入均保持原样。趋势使用独立纵轴及最小显示跨度，避免微小变化占满纵轴或上下刻度四舍五入后重复。EOF 前缺少结束 Trigger 的路径明确标为未闭合，不发布整路径判断。

停止、分析失败或服务重启后，未完成的云端路径统一标为取消，待处理计数清零，本地结果保留。云端各阶段前后检查取消信号，不再启动下一阶段请求；已经发出的同步请求可能等待本次超时，返回后仅保留已执行阶段及用量，不发布整路径云端类别。

`cloud.in_flight` 标记仍在执行的同步云端请求。停止后此标记会保留到请求退出，期间云端配置与连接测试继续报告占用；重新启动服务会清除旧进程的在途标记。正常关闭服务与意外退出均把活动任务保存为 `interrupted`，用户主动停止保留 `stopped`。事件日志或快照写入失败时，内存状态用 `metrics.persistence_error` 明确报告，不能把磁盘保存视为成功。

首次加载编码器与对应折使用独立模型锁，状态查询和停止接口无需等待加载完成。暂停耗时由控制接口累计，包含读线程等待计算队列期间的暂停；暂停接口返回前，正在处理的输入块与样本位置一并提交，继续后按补偿后的源时钟接收下一块。

10 倍速与最快档用于工程验证，采用有界背压，不属于实时延迟测量。1 倍速计算队列积压超限会明确停止并报告 `overrun`。

## 输入和输出合同

- 直接只读 CDT/DPO，默认 256 原始样本一块；只解析已经到达的内嵌 Trigger，不读取 CEO、问卷或目标标签。
- 1024 Hz、指定 30 EEG 通道、M1/M2 平均参考、50 Hz/Q30 陷波、四阶 0.5–45 Hz 带通、八阶 70 Hz 抗混叠低通，因果 SOS 后每四点降采样至 256 Hz。
- 启动和非有限值/缺样本后预热 5 秒。滤波状态跨路径和休息连续，窗口锚定原始事件和全局降采样相位，不跨断点拼接新窗口。
- 输入窗为 `30×1280`，5 秒无重叠；原峰峰值、非平直通道、完整路径至少 3 窗和 80% 窗口覆盖规则保持一致。不使用记录开头或休息段作为静息参考。
- 每窗只编码一次。三个领域共用本轮 Welch PSD，分别保留原有频带端点定义；数值工具缓存每窗频谱、协方差和滤波器组结果。
- 疲劳与额区指标用频带累计和计算前缀均值，只计入有效窗口；冻结 MIL 和八路工具的聚合定义保持原样。
- 模型过程读数是“截至当前的整路径类别估计”，未校准；它不是即时症状真值。完整路径本地结果和真实云端最终判断分列。疲劳/情绪领域报告 EEG 指标和变化。
- 同一记录加载其对应留一被试折；冻结清单没有对应折的记录只显示描述性工具，禁止默认使用其他折。

## API

| 接口 | 用途 |
| --- | --- |
| `GET /api/online/catalog` | 原始记录、模型与云端可用性 |
| `POST /api/online/sessions` | `{recording_id, speed:1, cloud:true, max_seconds:null}`；`speed` 可取 `max` |
| `GET /api/online/sessions?limit=20&offset=0` | 最新任务摘要，最多每页 100 条，不携带波形或事件 |
| `GET /api/online/sessions/{id}` | 状态、最新窗口、路径与资源快照 |
| `POST /api/online/sessions/{id}/control` | `{action:"pause"|"resume"|"stop"}` |
| `GET /api/online/sessions/{id}/events?after=N` | 有序 SSE，支持 Last-Event-ID 和过期游标快照恢复 |
| `GET /api/online/sessions/{id}/report` | JSON 报告 |
| `GET /api/online/sessions/{id}/report.md` | Markdown 报告 |

`max_seconds` 必须为有限值且至少包含一个原始样本（1/1024 秒）；超过记录长度时按实际 EOF 截止。SSE 游标若超过已产生的最大序号会返回 400，不会静默等待不存在的事件。

原始数据到达和计算完成时间分别记录。`processing_seconds` 是本地窗口分析耗时；`completion_lag_seconds` 包含源时钟调度、采流/滤波、排队及本地分析；`queue_processing_lag_seconds` 从入队开始计时。指标不包含云端等待或浏览器绘制时间。

窗口、进度、云端状态和会话状态事件携带当前 metrics/cloud/error，网页无需重连即可更新 P95 和错误原因。SSE 使用有界的预序列化事件缓存，正常轮询只读取游标后的事件；过期游标才生成快照。`metrics.produced_windows` 为采流端生成的窗口数，独立于推理完成计数 `total_windows`；`read_samples`、`source_samples`、`reader_complete` 和 `source_eof_reached` 用于区分完整 EOF 与受限回放。

在线会话位于独立 `outputs/online_sessions`，资产位于 `outputs/online_assets/seed2026`。默认事件日志保留 64MB×2 段；不含波形的 `evidence.jsonl` 保留 64MB×3 段。最多保留 8 个会话对象，已退出线程的旧任务按需从磁盘读取，列表采用分页摘要。历史会话文件保留，因此这些约束不是全局磁盘容量限制。服务重启后旧任务标为中断，不自动拼接成连续运行。树莓派配置可显式指定目录。

## 验证与部署

离线保护基准、全部原始流核对和模型对照位于 `outputs/online_implementation/20261011`。全量流一致性使用 26 份原始记录；模型及有标签评价分别注明对应 24 折和可评分集合，不将窗口数视为独立被试样本。

参见 [模型移植说明](ONLINE_MODEL.md)、[树莓派部署](ONLINE_DEPLOYMENT.md)。`scripts/evaluate_online_numeric.py` 分别评价前缀与完整路径，所有推理完成后再读取标签；冻结评分集为 24 被试、146 完整路径，High 阈值为 30。PC 测量只表示开发机性能；实机需要运行 `scripts/benchmark_online_pi.py` 完成 1 倍速完整回放及至少 2 小时稳定性测试。
