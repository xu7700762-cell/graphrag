# 多领域 EEG 对话工作台

## 原始波形自然语言分析

在对话框直接输入被试编号和综合问题，例如“被试10跑了多少条路径，疲劳相关指标、心理负荷指标如何变化，首条高类路径从哪里开始”。系统将编号用于本地文件定位，云端仅收到匿名问题、工具结果及方法知识。首次定位后，后续追问继续使用同一原始记录；对话中指定另一个被试会切换记录。研究参数的文件选择仅为可选入口，不是提问的前置步骤。

原始CDT由文件头读取通道和采样率，并直接扫描Trigger波形的20/22事件。不会读取CEO事件表、当前查询的标签CSV、问卷、MAT或历史预测。完整路径与尾部未结束片段分别统计。疲劳和心理负荷是明确计算的EEG指标及变化，不对应未验证的主观等级。VRMS使用冻结的训练参数重新编码原始窗口，再执行八路数值工具和融合；已知本地被试被排除在对应模型和案例支持之外。原估计器的训练数组留在本地，额外案例RAG仅返回匿名训练期类别和有限数值摘要，当前查询真值、身份与问卷仍不进入语言Agent。

原始分析的方法检索池限于带`raw-only`版本标记的已审阅内置资料，包括九路输入的量纲、分数边界、校准、相关性与冲突教学，并在云端分类之前送入。另有通过来源与被试隔离校验的冻结训练案例库：每折19名内部被试，最多12名不同被试近邻摘要及3条完整MIL＋八工具案例。案例来自缓存训练特征，标记`cached_training_reference / in_sample_not_OOF`，不能作为独立正确率或当前查询答案；没有改变冻结投票k或本地融合结果。数据介绍只摘取格式和事件协议；已上传知识文档可用于独立知识问答，不进入分类教学与真实案例库。

Supervisor 先给综合结论，再按所问主题和状态回答，不以 Agent 名称重复子报告。首末完整路径比较、完整休息段比较和最高片段使用当前执行工具的结构化结果，核验正文中的值、方向、状态、编号、时间及工具来源。网页过程展示逐项核验数量；工具声明齐全但正文漏答也会拒绝标记为已验证。首末端点缺测时不会换用另一段，最高排名排除未完成或缺测片段，并保留并列最高。

报告通过本轮事实编号选择来源，程序恢复精确source/path/value，并绑定同一事件段的编号与起止时间。总片段数、完整路径数和不完整片段数作为同一统计组保留。来源或正文校验失败最多允许一次带反馈的修正；仍失败时保留本地工具摘要。API连接或超时失败不自动重试。当前所选GPT或DeepSeek均可实际调用原始EEG分类工具，返回的云端类别独立于MIL和数值融合。

路径20→22与休息段22→下一20分别汇总各自完整片段的合格五秒窗口功率，再计算TAR和心理负荷比值；不是各片段比值的算术平均。记录开头已处于VR环境，不作静息基线，也不自动计为完整休息。原始模型不发送开头参考，数值特征使用已有无参考分支，冻结权重与训练归一化保持不变。网页保留旧回答并标出旧参考已停用；新结果保存comparison_policy=event_segments_only与baseline_policy=disabled。历史研究路径批量评价保留原有合同，不能据其ACC声称本无参考协议的效果。

`GET /api/brain/recordings`列出本地记录；`POST /api/brain/recordings/edf?filename=...`接收原始EDF二进制（上限512MB）。新网页会话显式使用`input_policy=raw_eeg_only`；旧研究入口已移除；新会话不接受研究路径或研究管线参数，旧研究对话仅供查看和下载。会话保存`recording_id`，SSE的`recording_selected`事件同步文件定位。EDF没有内嵌任务事件时，路径数显示“未定义”；不符合VRMS合同时，指标工具继续工作，模型分类明确说明具体缺失。

现有服务首页 `http://127.0.0.1:8880/` 为对话工作台，`/monitor` 为原 EEG 回放监测。无需新增前端构建工具或 Python 依赖。

```powershell
Set-Location -LiteralPath 'D:\桌面\2'
.\.venv\Scripts\python.exe -m eeg_agent serve --port 8880
```

## 操作与协作

新建网页对话默认真实云端 API 与原始 EEG 输入，可选择 VRMS、疲劳、情感的任意组合。三个 Agent 分析自然语言关联的同一份原始记录；也可在研究参数中选择文件或上传 EDF。发送问题后，页面显示 Supervisor 分派、领域 Agent 工具结果、检索引用、子报告及最终回答。可以继续追问、刷新恢复或下载 Markdown。旧研究对话按只读方式恢复，不能续跑或重新触发研究推理。

手动勾选设定默认领域。每轮问题明确要求“三个 Agent”时，前后端都会派发全部三个领域；明确提及眩晕、疲劳或心理负荷时，补齐该领域，不会被旧勾选静默遗漏。明确“只让 FatigueAgent”等限定可收窄本轮范围，泛化追问沿用当前范围。实际领域通过`domains_selected`事件同步到网页并保存；各领域报告只回答自己的测量，Supervisor汇总已参与领域。分类校验区分真实类别断言与缺少分类结果的说明，仍拒绝缺少来源、错层和数值冲突的真实断言。

VRMS 在网页统一显示为“VRMS 模型”。工作台只接收原始 EEG 文件或自然语言定位的本地被试记录；研究路径选择、训练种子控件及网页批量实验评价均已移除。历史实验产物保留，不能当作当前原始入口的准确率。

Supervisor 接收全局对话，分派任务并读取全部子报告。领域 Agent 只接收分配的任务、本领域此前子报告、登记工具与匿名测量；相互独立的任务并行执行。共享状态在领域报告完成后汇入 Supervisor。页面展示可核验的执行事件，不展示模型内部思维。

云端模式读取显式项目配置。首页可切换 DeepSeek / CPA GPT，两者分别保存接口、模型和密钥，下一轮使用所选接口。`/monitor#cloud` 可编辑这两套配置；CPA 默认 `http://127.0.0.1:8317/v1` 和 `gpt-6.1-sol`，使用 Responses API；DeepSeek 使用 Chat Completions。一轮正在使用云端时禁止更改配置。对话云端请求单次最多六十秒、无自动重试；原始EEG的VRMS云端工具循环最多四轮，GPT使用Responses，DeepSeek使用Chat Completions；两者先读取实际corrective_evidence再发布独立High/Low。显式选择“模拟调试”时真实执行本地工具与检索，文字使用模板，不调用云端。

两套配置存于本项目 `.env` 邻接的 `cloud_profiles.json`，当前启用项同步到 `.env`。不读取其它应用登录凭据；网页密钥不回填、不写入浏览器存储或报告。空密钥只保留同配置档原有密钥，不能把 DeepSeek 密钥复用到 CPA。

每条最终回答保留生成来源：`cloud_verified` 表示真实 API 文本通过证据校验，`fallback` 表示汇总失败后使用本地模板，`mock` 表示模拟，旧报告没有来源记录时为 `unverified`。`workflow_status=partial_fallback` 表示部分计划、领域报告或所选云端分类失败，即便最终 Supervisor 文本成功也会显示降级状态。

## 原始 EEG 工具与数据

VRMSAgent 调用 `vrms.raw_recording` 和 `vrms.raw_model`；FatigueAgent 调用 `fatigue.raw_spectrum`；EmotionAgent 调用 `emotion.raw_workload`。同一原始文件的预处理窗口和频谱指标可复用内存缓存，VRMS 编码、MIL 和八路数值工具每轮实际执行。旧研究对话及实验文件保留用于查阅；网页没有旧研究目录或批量评价接口。

## 分层知识库

包内 `eeg_agent/brain_knowledge/` 含 `shared`、`vrms`、`fatigue`、`emotion` 四个目录。当前提供九份来源可追溯的种子资料，包括本地协议、BrainAgent 原文、情感 Copilot 原文与明确标记的二级文献线索。该种子库不是完整领域文献库，也不是论文官方语料。

每个领域 Agent 完成工具后，检索共享库和自己的专属库，最多召回二十个 BM25 候选，在候选集重新评分后取最多五条。当前是本地词法检索，没有加载论文中的 MiniLM 向量模型或交叉编码器。引用记录保留领域、来源类型、章节、页码、来源 SHA256 和片段哈希；未找到匹配内容时返回证据不足。

网页知识库页面可向共享或指定领域导入文本，填写标题、来源及可选 DOI/页码。导入资料保存到 `outputs/vrms_v2/brain_knowledge/` 并立即参与检索。导入内容始终标为 `user_supplied`；填写 DOI 不意味着已核验全文或来源。

## 接口与保存

`/api/brain/catalog` 返回原始 EEG 领域工具和库摘要；`/api/brain/sessions` 创建或列出对话，原始分析使用 `recording_id` 和 `input_policy=raw_eeg_only`，不再接受 `pipeline_id` 或 `vrms_path_id`；会话的 `messages`、`events`、`report` 分别用于消息、可续传 SSE 和报告；`/api/brain/knowledge/search` 检索，`/api/brain/knowledge/documents` 导入资料。

旧 `/api/brain/vrms/catalog` 和 `/api/brain/vrms/evaluations` 系列接口已移除，访问返回404。旧研究会话仍可读取消息和下载报告，但提交新消息返回409，提示新建原始 EEG 对话。

完整对话、事件和报告保存到 `outputs/vrms_v2/brain_sessions/<id>/conversation.json`。运行时同一对话不能并发提交两轮；服务重启后保留历史，并将未完成轮次标为中断。每个会话最多五十轮。

## 论文与实现范围

BrainAgent，arXiv:2606.25400：PDF 第三至四页提供 Supervisor、子 Agent 与共享状态；第七页提供执行轨迹示意；第十三至十四页提供共享/领域知识库及工具后检索。论文图片属于方法与执行示意，本工作台是针对现有 VRMS 项目重新开发的界面。独立 FatigueAgent 属于本项目扩展。

本次工程验证不等于疲劳/情感工具解释的有效性、RAG 增益、真实 API 效果或树莓派性能验证；这些需要各领域数据、工具及输出合同、独立验证和硬件测量。
