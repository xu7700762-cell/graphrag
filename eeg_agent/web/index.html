当前运行协议

监督与数据
24人、147条CSV候选路径，146条原始事件完整路径。评分<30为低、≥30为高。训练87、验证36、测试23条路径，被试互不重叠；窗口没有逐时症状真值。
输入合同
30通道、256 Hz、5秒1280点、μV。乳突参考、因果50 Hz陷波、0.5–45 Hz带通及抗混叠；状态跨路径和休息连续，断流重新预热10秒。P0为原处理，P1增加先行基线初始化的因果眼电回归；任务冻结算法与参数，自适应系数仅由已到达样本更新。模型只能接受其训练及导出合同对应的处理配置。P1校准不足时持续质量测量，预测不可用。
模型与发布
EEGNet或EEGConformer，由用户在任务开始前选择并冻结。每种检查点具有独立归一化、温度与阈值；至少3个有效窗口、80%有效覆盖才能发布路径类别。辅助工具不能改写类别。
基线与时间
只取首任务前已到达的合格基线，预热后至少10秒、最多60秒。最近30秒趋势至少3个有效窗；连续3窗达到阈值只称为模型持续高类候选段，不称为真实症状onset。
云端与证据
Supervisor和VRMSAgent通过云端API调用；本地工具、依赖、预算、阈值及输入检查具有执行约束。每任务50次上限、10秒超时、不自动重试。原始数组、身份、评分与真实标签不上传。
部署与成本
树莓派承担本地运行，Windows负责训练与首轮验收。Windows延迟、mock报告和加速吞吐分别标注，不能代替Pi或真实API实测。
