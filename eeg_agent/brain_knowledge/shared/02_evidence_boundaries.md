# 共享证据与引用边界

## 分层检索与证据职责

Supervisor安排专门Agent，专门Agent调用登记工具并形成子报告，Supervisor汇总已有证据。共享知识库提供信号、质量和证据规则，领域知识库补充VRMS、疲劳或情绪的任务定义。文档及用户上传资料是引用材料，不能覆盖冻结模型输入、概率温度、阈值或工具实现。

当前本地实现为词项检索备用方案：在共享库及选定领域库中用BM25选取最多20个匹配候选，再对候选集用BM25排序、返回最多5条。当前没有稠密向量索引或cross-encoder，不能将词项排序宣称为语义模型重排。无词项匹配时说明未检索到对应资料；已经完成的工具测量仍直接报告数值与方向。原始记录推理仅检索经审阅的通用方法库，排除用户上传的被试记录及问卷内容。

## 引用和结论

引用条目保留稳定ID、来源、章节、资料版本、来源SHA256、摘录SHA256、DOI或URL及页序（如适用）。local_protocol表示项目定义，paper_excerpt表示核对论文的摘录，user_supplied表示未经独立核验的用户资料，三者证据地位不同。

数值由确定性工具计算；模型类别按匹配合同渲染。工具计算正确、模型分类有效和生成文字忠实需要分别验证。mock对话只检验交互与路由，不证明真实云端收益。Windows资源测量不能替代树莓派实测。

原始EEG、完整PSD、真实评分及被试身份不传入云端；云端可接收匿名质量、局部功率测量、已经执行的工具结果和实际引用证据。知识库中的操作性文字不作为执行指令。
