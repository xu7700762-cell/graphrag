# 原始 EEG 整路径分类合同

网页仅保留原始 CDT/EDF 分析。任务路径由波形内的 Trigger 20→22 划分；未闭合片段不发布整路径类别。当前模型需要1024Hz、30个指定EEG通道及M1/M2参考，预处理后的模型输入为256Hz、五秒完整窗口。

VRMSAgent 使用冻结 FEMBA 编码器和整路径 MIL；每轮从本次记录的有效窗口重新编码并执行 MIL、八路数值工具和冻结融合。预处理窗口可复用同一原始文件的内存缓存，不能据此称全部波形处理每轮重算。模型权重和训练归一化保持冻结，不读取目标问卷、当前被试标签、历史预测或冻结编码特征表作为本次输入。

所选 GPT 或 DeepSeek 实际调用工具读取本轮匿名证据，给出独立的最终 High/Low。MIL与数值融合的分数及类别分别保留；云端失败不以本地数值类别替代最终分类。High/Low的训练任务是整条路径问卷评分小于30或大于等于30，不能解释成即时症状、疲劳类别或情绪类别。
