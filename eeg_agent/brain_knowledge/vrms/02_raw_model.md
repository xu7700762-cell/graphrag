# VRMS 原始波形推理

## 工具与分类

vrms.raw_recording从原始Trigger波形确定任务片段及完整性。vrms.raw_model将同一原始EEG重新处理并编码，执行冻结的VRMS整路径MIL、八路数值工具及融合权重。没有读取目标问卷、当前被试标签、预测表或冻结编码特征缓存。数值工具内的训练期拟合参数保留在本地模型内部，不作为被试答案交给语言Agent或RAG。已知本地被试使用将其排除在拟合之外的对应模型；新上传的兼容EDF使用预先固定的部署权重，不将此输出宣称为已验证的外部泛化性能。

真实API模式默认由当前所选GPT或DeepSeek独立判读器接收MIL、八工具实际读数、内部验证资料、方法教学与percentile_group参考案例，返回六字段离散High/Low及定性置信度。数值融合类别和分数不进入这一判读请求，MIL、数值融合、云端最终类别分别保存。数值工具在云端请求前从原始EEG重新计算；云端不处理波形、不产生新概率。所选接口未配置、调用失败或格式/引用校验失败时，不发布云端类别，不用数值结果替代。路径缺结束事件、合格窗不足或覆盖率不足时不分类；其余已完成路径仍逐条报告。

记录开始已处于VR暴露环境，本入口不发送开头参考波形，不计算相对该参考的谱变化。数值工具沿用训练定义的无参考分支：相对变化特征为零并将参考可用标记置零；训练拟合的归一化与模型权重保持冻结。路径内前后差仍取同一路径真实窗口。历史使用开头参考的融合结果及ACC不能视为本无参考协议的验收结果。

## 分类前的方法与案例RAG

方法RAG在云端分类前提供MIL加八工具的字段、量纲、边界、校准、相关性和冲突判读解释，详见[九路证据教学卡](03_nine_evidence_guide.md)。

默认案例RAG入口为eeg_agent.default_rag，版本raw_decisive_rag_v4 / percentile_group。按八工具在参考库中的经验百分位，等权比较FEMBA、频谱、空间/CSP、案例检索四来源组；MIL不参与距离。每类取至多两条核心案例并优先覆盖不同内部被试，必要时补足，最多六条。展示参考类别、原始读数、校准值、检索距离及整库统计；排除当前查询被试、当前问卷、真值及历史云端答案。参考来自同折内部policy被试，未参与头和校准器拟合，但参与过selector开发，不能称独立外部验证。缺失或哈希不符时明确不可用，不静默退回旧案例。首页与在线完整路径结束判读共用此入口；后续已验证RAG优化同步成为默认，不再等待另一次切换要求。

## 高类时间的位置

工具按原始时间排列已分类完整路径，返回第一条云端最终判为High路径的起止时间。该判定使用整条路径的数据，最早在该路径结束后形成，不能据此定位该路径内部首次出现真实眩晕的秒数。回答采用“在已完成云端判断的完整路径中，首条高类是第几条，起止时间是多少”的明确格式。全部已分类路径均为Low时直接报告“已完成云端判断的完整路径未检出高类”；全部分类失败时只能报告“分类未完成，无法确定高类路径”，不得写成“首条高类不存在”。本无参考原始协议尚未重新评价ACC，历史71.92%不能作为本入口的准确率。
