# BrainAgent中的疲劳与工作负荷文献线索

## 原文工具职责与本项目扩展

BrainAgent的附录A.3将Theta/Alpha Ratio (TAR)及MentalWorkloadCalculator归在EmotionAgent工具包中：前者用于论文描述的嗜睡和疲劳检测，后者分析精神疲劳及认知工作负荷相关EEG模式和时间趋势。本项目将FatigueAgent单列为新扩展，不将这一领域拆分说成BrainAgent原有的独立Agent。（PDF页序13）

这些描述提供工具与知识库组织的参考，不证明本项目的theta/alpha、theta/beta或时间斜率已经具有疲劳分类效度，也不提供可直接迁移到城市巡航数据的诊断阈值。
