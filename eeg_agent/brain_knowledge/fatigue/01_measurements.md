# 疲劳Agent的频谱测量合同

## 可计算的频谱比值

FatigueAgent是本项目新增的领域扩展。它读取已到达、质量合格的区域delta、theta、alpha和beta绝对功率，确定性计算theta/alpha、theta/beta、beta/alpha及(delta+theta)/(alpha+beta)，保留公式与单位。以上是沿用当前频谱工具的测量定义，不是已验证的疲劳评分。

可以报告各区域比值及同处理配置先行基线的功率变化。分母缺失、非有限或接近零时明确缺失；缺基线时不能伪造基线变化。需要至少3个已到达、时间递增的频谱比值窗口才计算每分钟斜率。

## 测量与疲劳的边界

当前城市巡航路径标签定义晕动症评分高低类，不能当作疲劳真值。VRMS模型概率的均值、斜率、持续高类窗口不能转换为疲劳趋势。频谱比值受眼电、睁闭眼、处理参考、任务和被试差异影响；本项目尚未验证任何比值阈值能判定疲劳。

本版 FatigueAgent 采用 EEG 工具分析模式，不使用也不要求部署深度学习分类模型。工具提供实际频谱比值与时间趋势，Agent 检索共享库和疲劳领域库，再调用真实大模型 API 解释指标、适用条件与所缺证据，由 Supervisor 汇总。未取得 EEG 时可以进行知识问答；缺失分类器不影响工具分析。

工具分析报告不宣称疲劳分类效度。若以后需要评价疲劳类别，应另外建立独立疲劳标签、隔离被试的验证及覆盖报告，不能把当前测量或大模型解释当作经验证的疲劳标签。
