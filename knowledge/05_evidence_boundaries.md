# 报告、RAG 与研究结论边界

资料版本：2.0
证据类型：项目报告规则

## Agent 的职责

Supervisor 理解自然语言需求、安排分析并汇总；VRMotionSicknessAgent 调用登记数值工具、读取结构化证据并形成子报告。树莓派本地运行预处理、模型、频谱、协方差、时间监测、规则、知识检索和网页服务，LLM 使用云端 API。云端仅接收匿名摘要，不接收原始 EEG、实际评分、被试身份或测试标签。

## 证据引用与数值

知识检索使用本地 BM25，按标题与段落切分，目标 600 字符、重叠 100 字符，最多返回五个实际匹配条目。每个引用保存稳定 ID、来源、章节、资料版本及内容和来源哈希。无匹配时明确证据不足。知识资料不能覆盖冻结输入合同、模型或阈值；数值和类别由本地证据渲染。缺少引用、引用无效、数值冲突或 API 失败时使用确定性报告并记录原因。

## 验证层级

分别评价路径分类效度、数值工具正确性、时序操作规则正确性、报告证据质量及运行成本。Windows 资源结果不等于树莓派实测，mock Agent 验收不等于真实云端收益。当前没有逐时症状标签，不能报告真实 onset 准确率、症状提前量、即时严重度或独立症状置信度。正式分组五折、真实云端收益和 Pi 硬件性能需要独立验收。
