# 语义 GraphRAG v1 实施与验收

首页与在线路径结束判读已接入显式 `semantic_graph`，固定 `raw_eeg_state_graph_v1 / state_reasoning_v1` 和 `semantic_state_high_v1` 判读协议。默认仍为普通 RAG 的 `percentile_group`；新版尚未完成 146 条新的真实云端分类评估，不声明 ACC 或 BACC 改善。

新增静态语义图只包含已核验的论文与方法关系，候选知识不能进入判读请求。实际 EEG 观测由路径首末三分之一的频谱变化生成，频谱读数不能替代静息基线或症状真值。新模式保留同折 v3 案例与边界反例，支持路径、反证及证据强度独立呈现。动态模型证据仅存于当前会话，不写入参考库。

会话创建时固定知识清单、语义模块、观测模块、判读模块、v3 模块与固定普通基线哈希；旧会话继续使用创建时记录的 policy。`/api/brain/catalog`、`/api/online/catalog` 与 `/api/rag/version` 返回相同版本信息及 `promotion_status=not_evaluated`。

工程验收记录分别保存在 `engineering_audit.json` 和 `validation/semantic_actual_observation_check.json`。前者逐一核验 146 条历史数值输入的同折检索、标签隔离、六字段上下文和引用合同，历史输入没有真实生物标志观测，不能用作新版性能评估。后者使用实际完整 EEG 路径，核验增量与批量观测一致，MIL、八工具读数与原始特征不变，实际返回支持与反证路径。二者均不调用真实 LLM。

新版部署包通过 builder 白名单生成，含新模块、知识 sidecar、语义资产、v3 与旧固定依赖、构图与审计脚本。包内每项 SHA256、CRC、文件集合均经实际 archive 校验，版本来自打包时的 `catalog_fields()`。新部署包、清单及证据单独保存，历史部署包、清单与 20261011 报告保留。

切换默认需要新的 146 条有效语义判读、至少 112 条正确、BACC 不低于普通固定基线、全部来源与引用和工程检查通过。当前未满足真实分类评估条件，保持显式实验入口。
